Phase 3 map: where we are and where we're going

Session notes for understanding, not committed to the repo. Source of truth: private/CLAUDE.md (roadmap) and private/LEARNING.md (Phase 2 retrospective).

1. The goal in one sentence

Take the baseline RAG apart one stage at a time. For each stage: learn the options, build 2–3, measure each against the baseline, keep the winner. The point is that you can explain every stage and why we chose what we chose, with numbers.

2. The loop we repeat for every stage

1 Teach→2 Build 2–3 methods→3 Change ONE thing, score working set→4 Compare with previous result→5 Keep winner, log it

You choose which methods to build ("ask, don't assume"). Log goes to EXPERIMENTS.md; the lesson goes to LEARNING.md.

3. The pipeline and what each stage fixes

Ingest→Chunk→Embed→Index→Retrieve→Rerank→Generate

Order is open: roadmap order, or biggest-failure-first. Both start at chunking because ingestion is done. Ragas runs alongside, after the first couple of changes.

Retrieval gap (0.81 → 0.96 with perfect passages) is why retrieval-side stages come first.

5. Rules that never change

  • One variable at a time; score the working set after each change.
  • Held-out set only at milestones, with --confirm-milestone. Never tune on its failures.
  • Do not change the judge without a new calibration (fingerprint 2578221ecdd4).
  • Report retrieval numbers with and without the summary passages.
  • Do not edit eval questions to flatter results.
